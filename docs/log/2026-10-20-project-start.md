# Project start

## In plain words

Day one. We wrote down what we want, built the tools, downloaded the data, ran the first tests, read the research, and set up the website. Nothing beats the stock market yet.

## What happened

- Wrote down the initial intent ([INT-0001](../intent/0001-initial-intent.md)): find out whether a currency strategy can beat the S&P 500, as research rather than a business, with a dashboard of leading indicators and strategies that can be swapped out.
- Set up the repo, the research engine, the dashboard, CI/CD and the docs system ([DEC-0002](../decisions/0002-free-tier-stack.md), [DEC-0004](../decisions/0004-docs-are-checked-by-a-script.md)).
- Built scrapers for 30 free series: 9 G10 currencies, 10 interest rates, oil, gas, copper, SPY and the VIX ([REF-0003](../reference/0003-data-sources.md)). Stooq turned out to be behind a browser check, so we dropped it. FRED's CSV link stalls for Python clients, so the engine calls curl for now.
- Ran the first baseline ([EXP-0001](../experiments/0001-baseline-backtests.md)). Carry, trend and the commodity gap all lose to SPY. The commodity gap's signal looks more informative at longer horizons than the one it trades at, which is the first real lead.
- Surveyed the literature, books and courses ([RES-0001](../research/0001-reading-list.md)). The most important finding is that published FX factors have decayed sharply since publication. Added four hypotheses from the literature ([HYP-0004](../hypotheses/0004-macro-surprises-move-fx-predictably.md) to [HYP-0007](../hypotheses/0007-sp-500-plus-fx-beats-sp-500-alone.md)).
- Started surveys of open-source projects and public bot results, including crypto ([RES-0002](../research/0002-open-source-and-public-results.md)), and of practitioner forums ([RES-0003](../research/0003-forums-and-practitioners.md)).
- Built the gauntlet, eleven fixed tests every strategy faces ([REF-0006](../reference/0006-the-gauntlet.md)), and wrote up the first full run like a short paper ([EXP-0002](../experiments/0002-baseline-gauntlet.md)). Nothing beats the S&P 500. Carry looks like a small real effect. The oil idea shows nothing as built, with one clue now recorded as [HYP-0008](../hypotheses/0008-monthly-commodity-gap.md).
- Added a 75-term glossary with simple, analogy and precise explanations ([REF-0004](../reference/0004-glossary.md)), a Learn tab on the dashboard, and a rule that every doc starts with an "In plain words" section.

## Decisions

- Cloudflare Pages over Vercel for the dashboard, because Vercel's free plan blocks deploys from other people's commits on a private repo ([DEC-0002](../decisions/0002-free-tier-stack.md)).
- No microsecond trading in the proof of concept ([DEC-0005](../decisions/0005-no-microsecond-trading-in-the-poc.md)).
- A strict definition of beating the S&P 500 ([DEC-0006](../decisions/0006-how-we-define-beating-the-sp-500.md)).

## Open questions

- Which free source gives point-in-time consensus forecasts for macro releases?
- Should the headline comparison be FX against SPY, or SPY plus FX against SPY ([HYP-0007](../hypotheses/0007-sp-500-plus-fx-beats-sp-500-alone.md))? For now we report both.
- Who on the team takes which hypothesis first?
- Which tool did we mean by "zenpilot"? The survey guessed Zenbot, an archived crypto bot ([RES-0002](../research/0002-open-source-and-public-results.md#what-zenpilot-probably-means)).
