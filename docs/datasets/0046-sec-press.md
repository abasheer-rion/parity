## Terms and quality

**Terms:** Public domain US government work. Callers must send a user agent with a name and contact email. https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data

**Quality:** Runs only when PARITY_CONTACT is set, because the SEC asks callers to identify themselves.
