# OECD Data API (SDMX)

## In plain words

A club of rich countries that collects the same economic numbers from each member so they can be compared side by side.

## Summary

Key economic indicators by country: short and long interest rates, inflation, leading indicators and GDP. It is the original source of the 3-month interbank rates we pull through FRED.

## Terms and quality

**Terms:** Most OECD content since 1 July 2024 is under CC BY 4.0, so reuse is allowed with attribution, but third party material is excluded (source: search summary of https://www.oecd.org/en/about/terms-conditions.html, page blocked to us).

**Quality:** The API serves revised values only. Updates arrive with a lag; euro area and UK 3-month rates currently stop at 2026-01. We pulled the US 3-month rate to 2026-09 with no key (tested).
