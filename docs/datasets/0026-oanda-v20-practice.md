## In plain words

A pretend trading account at a real currency broker. A program can see real prices and place fake trades.

## Terms and quality

**Terms:** Standard OANDA account and API terms; we did not read the data redistribution terms. Treat as personal use only.

**Quality:** Prices are OANDA's own quotes with its spreads, not the interbank market. Demo accounts may close after inactivity (third party report, unverified). The practice endpoint returns 401 without a token (tested).
