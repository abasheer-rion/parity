# Forex Factory weekly calendar export

## In plain words

A free list of this week's big economic announcements and what experts expect each one to say.

## Summary

This week's economic events with title, country, time with time zone, impact level, forecast and previous value, as JSON from nfs.faireconomy.media. There is no actual value field.

## Terms and quality

**Terms:** Main site blocks our reader (HTTP 403), so terms are unread. Personal research use only, no redistribution.

**Quality:** Only the current week, so we must save a copy every week to build our own history of forecasts. Forecast values can change during the week. The Hugging Face archive warns values may have been edited after the event.
