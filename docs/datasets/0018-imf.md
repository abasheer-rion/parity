# IMF Data API (SDMX 2.1 and 3.0)

## In plain words

The world's emergency lender for countries publishes a lot of numbers about every country's money and trade.

## Summary

Exchange rates, interest rates, reserves, balance of payments, CPI, the World Economic Outlook and primary commodity prices (the source of our copper series).

## Terms and quality

**Terms:** Free to download, copy, publish and redistribute with attribution to the IMF, without altering the data. Commercial reuse needs written permission (copyright@imf.org). https://www.imf.org/en/about/copyright-and-terms

**Quality:** Mostly monthly or slower. The dataflow list includes named monthly vintages for some datasets (for example CPI_2026_FEB_VINTAGE), but only recent ones, so it is not a long point in time history. The swagger explorer asks for a sign in even though plain calls work.
