# World Bank Indicators API and Pink Sheet

## In plain words

The World Bank keeps a long list of what oil, metals and food cost each month going back to 1960, plus yearly facts about every country.

## Summary

The Pink Sheet has monthly prices for oil, gas, coal, metals, food and fertilizers since 1960. The Indicators API has annual development numbers such as GDP.

## Terms and quality

**Terms:** World Bank data is generally under CC BY 4.0 through its data catalog; the commodity page points to that licensing. Website terms: https://www.worldbank.org/en/about/legal/terms-and-conditions. Catalog licenses: https://datacatalog.worldbank.org/public-licenses

**Quality:** Monthly averages, so too slow for daily signals. The file notes past revisions (some oilseed months were updated) and that some recent prices are World Bank estimates. Next Pink Sheet update is 2026-11-03.
