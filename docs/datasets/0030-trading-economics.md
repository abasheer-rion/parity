**Terms:** Paid subscription only. The trial fee is not refundable and renews automatically unless cancelled. https://tradingeconomics.com/api/pricing.aspx

**Quality:** The free guest:guest login now returns HTTP 410, the guest account has been discontinued (tested 2026-10-20). Unknown whether stored forecasts are as known before each release.
