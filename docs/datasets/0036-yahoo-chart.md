# Yahoo Finance chart endpoint

## In plain words

The back door to Yahoo Finance's price charts. It tells us how the S&P 500 fund did each day, counting dividends.

## Summary

Daily prices for stocks and ETFs, including an adjusted close that folds in dividends and splits. We use it for SPY, our benchmark.

## Terms and quality

**Terms:** No official API or data license. Yahoo's terms forbid commercial use and automated collection of data without permission, so our use is a gray area at best. Keep raw data private. https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html

**Quality:** Unofficial and can change or disappear without notice. Adjusted closes are recomputed after each dividend, so past values shift. Fallback is FRED SP500 plus a dividend estimate.
