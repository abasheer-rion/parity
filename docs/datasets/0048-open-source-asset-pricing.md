# Open Source Asset Pricing

## In plain words

Two economists rebuilt about 200 published stock-picking rules from scratch and posted how each one did, both during the years its paper studied and in the years after it came out.

## Summary

212 stock return predictors replicated from published papers, plus 114 placebos. For each: monthly long-short portfolio returns built the original paper's way, firm-level signal values (CRSP permno by month) and a signal document with the paper, its publication year, its sample start and end years and the paper's own return and t-statistic.

## Terms and quality

**Terms:** Data on Hugging Face are marked CC BY 4.0 (commercial use allowed with credit); cite Chen and Zimmermann (2022), Open Source Cross-Sectional Asset Pricing, Critical Finance Review. The code on GitHub is GPL-2.0. Rebuilding the CRSP-only signals (size, price, short-term reversal) needs a WRDS subscription. https://huggingface.co/datasets/OpenSourceAP/CrossSection

**Quality:** Each release rebuilds the full history, so past returns change: 26 of 212 predictors moved materially in 2026.10 (bug fixes, the CRSP v2 switch, IBES revisions), listed in the release notes. Returns are gross of trading costs. Pin the release branch (Data-Release-2026.10) for anything that must be reproduced. US stocks only.
