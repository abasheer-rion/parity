# ISO 4217 currency code lists

## In plain words

The official list of every three letter currency code, including the ones that no longer exist.

## Summary

List One: every current currency and fund with alphabetic code, numeric code, minor units and the countries that use it. List Three: every withdrawn currency with its withdrawal date.

## Terms and quality

**Terms:** SIX says it maintains the code lists "on behalf of the International Organization for Standardization (ISO)" and makes them "available online and free of charge". No other licence text was found on the page (checked 2026-10-21). robots.txt allows /dam, where the files live. We cite ISO 4217 and SIX as the source.

**Quality:** Withdrawal dates are free text: usually YYYY-MM but sometimes a range such as 1989 to 1990. A code can be withdrawn more than once (VEF has three rows). Fetched with no key (tested 2026-10-21): 178 current and 152 withdrawn rows, 307 distinct codes.
