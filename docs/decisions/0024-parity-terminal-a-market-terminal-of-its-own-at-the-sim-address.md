# Parity Terminal, a market terminal of its own at the sim address

## In plain words

The sim address (`sim.endyland.com`, or `/sim/` on previews) is now Parity Terminal, a product of its own. It looks and works like a market terminal:

- **Dark and dense, run from the keyboard.** A command bar sits at the top. Type a code such as `MON` or `WMAP`, or a name such as `EUR`, and press Enter.
- **Panels.** Each workspace is made of panels that you can split, resize, maximise and close. Picking something in one panel updates the others.
- **Five saved workspaces:** Overview, Macro, FX, Commodities and Sim lab.
- **A market monitor of every series we hold.** Each one shows its last value, its moves over a day, a week, a month and the year, its volatility, how unusual this week was, where it sits in its past year, and a small chart.
- **Comparisons**, a world map, headlines and strategy results.
- **Every Sim World tool**, all with the same replay.

It installs as an app. Every panel shows the date its data is from, and every simulation is labelled as history, not a forecast. The owner asked for "pretty much like a bloomberg terminal, eventually will be an app".

## Context

[DEC-0020](0020-sim-world-plays-every-tab-like-the-race-on-its-own-full-screen-site.md) put Sim World on its own full-screen site, but it still looked like the research app with tabs. The owner wanted an entirely different interface: its own dashboard, simulation options, comparisons, the interactive map, and access to every number we have.

## Decision

1. **A new shell, the same parts.** The terminal has its own layout, colours, command bar and workspaces (`web/src/terminal/`). The Sim World tools from DEC-0016 and DEC-0020 are reused as panels, and the terminal recolours them to match.
2. **Function codes.**

   | Code | What it opens |
   |---|---|
   | `MON` | Market monitor |
   | `WMAP` | World map |
   | `CMP a b` | Compare two series or strategies |
   | `CORR` | Correlations |
   | `SCEN` | Scenario |
   | `PATH` | Paths |
   | `STRS` | Stress test |
   | `CRIS` | Crises |
   | `RACE` | Strategy race |
   | `CRV` | Curves |
   | `COT` | Positioning |
   | `ECO` | Macro |
   | `HEAT` | Heat map |
   | `MOV` | Top movers |
   | `NEWS` | Headlines |
   | `KPI` | Strategy results |
   | `HELP` | Help |

   Typing a series name opens its detail panel. The bar autocompletes and remembers what you typed. Ctrl+1 to 5 switch workspaces, and F1 opens help.
3. **Data, loaded a piece at a time.** `parity terminal export` writes a small index and one file per series.
   - The index holds the latest numbers and statistics for every series.
   - Each series file has daily points from 2016 and weekly points before that.
   - The page loads the index first and a series file only when a panel needs it.
   - The deploy writes these files next to `world.json`.
4. **Only data we may show.** Each series carries its source and a plain licence note. The export follows the catalog's site flag and REF-0015, so some sources are never shown:
   - S&P index data and Yahoo prices;
   - IMF commodity prices;
   - personal-use feeds;
   - Hyperliquid perps, until the owner decides (DEC-0018).

   CoinGecko prices carry its attribution link.
5. **App-ready.** `/sim/` has its own web app manifest and a small service worker. The worker keeps the shell available offline and never stores data files. The terminal's code and assets are built under `/sim/assets/`, so the sim address serves everything itself.
6. **Back stays.** The one Back button next to the Parity mark works as before.

## Consequences

- The research side now describes and links Parity Terminal. `#/sim` there stays as a card that opens it.
- Many of the newer series need a fresh `parity fetch` before they appear: ECB, Treasury, BIS, CFTC, EIA and the extra FRED series. The monitor shows what the data cache holds.
- At phone width the terminal shows one panel at a time under the command bar.
- A later desktop or mobile app can wrap the same `/sim/` build.
