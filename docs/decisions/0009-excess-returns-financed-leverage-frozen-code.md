# Score on returns above the T-bill, charge for borrowing, and freeze code with each plan

## In plain words

Our independent audit caught two mistakes in how we scored strategies. We were letting strategies count the safe interest that cash earns as if it were skill, and we let them borrow money for free. We fixed both. We also made sure each test plan locks the exact code it will run, and we now stamp our record with an outside timestamp that we do not control.

## Context

[RES-0008](../research/0008-independent-audit.md) showed that a strategy holding only cash passed all six "beat the market" tests, because Sharpe ratios ignored the risk-free rate. Leverage cost nothing, and the "same risk" test compared a strategy at 15% volatility with a market at 19%. Registrations froze parameters but not code.

## Decision

1. **Every Sharpe, Sortino, deflated Sharpe, bootstrap and placebo uses returns above the 3-month T-bill.** CAGR and drawdowns use total returns.
2. **Funded strategies** (stocks, cash) pay the T-bill plus 0.5% a year on anything borrowed. **Self-financing currency books** earn the T-bill on their collateral, so totals compare fairly.
3. **Test A2** now scales the strategy to the market's own volatility over the same dates (currency books up to 10 times notional, funded books up to 4 times, paying for borrowing), and is marked "not testable" if that volatility cannot be reached.
4. **The stocks plus currency trend overlay** keeps its idle half in cash.
5. **Negative controls:** tests now require that holding cash earns exactly nothing above the T-bill and fails the gauntlet.
6. **Code is frozen with each plan.** An official run refuses to start if anything in `engine/src` changed after the registration was committed.
7. **Outside timestamps.** Each registration and each ledger update is stamped with OpenTimestamps, anchored in Bitcoin, which we cannot alter.

These are bug fixes and integrity fixes, not changes of pass thresholds, so they apply to all future runs. RUN-000001 to RUN-000003 stay in the ledger as recorded, scored the old way.

## Consequences

- With the fixes (exploratory run, 2026-10-21): the market's Sharpe is 0.43, not 0.54. Currency carry's is 0.41, nearly level, and at the market's volatility it earned 10.8% a year against 8.8%. Carry now passes 5 of 11 tests. Nothing passes all six "beat" tests.
- EXP-0004 and RES-0007 describe the old scoring. They must be read with this decision in mind until the official rerun replaces their numbers.
