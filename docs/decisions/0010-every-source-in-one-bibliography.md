# Every source we rely on is in one checked bibliography

## In plain words

Every paper, data set, piece of code, web page and forum post we use is listed once, with a full citation and a note on whether we could check it. Any page that uses a source links to it, and the checker refuses a link or citation that is not on the list.

## Context

The owner asked for full sources and citations for everything we go off of. Our sources were scattered across the catalog, the research notes and plain links.

## Decision

- `scripts/references.py` builds `docs/_system/references.json` from every link in the catalog and the docs, with full details from Crossref and arXiv where a paper has a DOI or arXiv id. Keys stay the same across reruns.
- `docs/REFERENCES.md` is generated from it: full citations grouped by type, the date first used, the result of the source check, and every page that cites each source.
- Docs cite with `[@key]`. The docs check fails on an unknown key, and on any external link that is not in the bibliography.

## Consequences

- 553 sources on 2026-10-21. 112 have full details from Crossref or arXiv. Most web pages, forum posts, code and data sets have no author or year to record.
- Adding a source means rerunning `python3 scripts/references.py` before `docs.py index` ([GDE-0003](../guides/0003-writing-docs.md)).
