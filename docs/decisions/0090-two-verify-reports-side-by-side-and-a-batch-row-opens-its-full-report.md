# Two Verify reports side by side, and a batch row opens its full report

## In plain words

Two trading records can now sit side by side at `/verify/compare/`, such as two bots someone is choosing between. Each side is a shared report link or a trade file checked right there in the browser. The page shows both verdicts, the same numbers in the same rows, both growth lines over the days they share, the checks each failed and what each could not show. It never says which to choose. On the firms' batch screen, each account's name now opens that account's full Verify report in a new tab.

## Context

Every check now ends in one report that travels in a link ([DEC-0089](0089-every-verify-check-ends-in-one-report-that-can-be-shared-and-printed.md)). The owner asked for a way to put two records next to each other. Parity checks records and never ranks them by return ([DEC-0079](0079-parity-is-an-ai-native-verification-platform-for-retail-traders-of-all-sizes.md)). A firm screening many accounts ([DEC-0087](0087-free-pilots-for-prop-firms-with-a-batch-screen-a-back-test-and-a-sample-report.md)) saw one line per account and no way to look closer.

## Decision

1. **Compare** at `/verify/compare/#a=...&b=...`: both reports travel after the "#", like a shared report, so a comparison is a link and Parity stores nothing (`web/src/verify/ComparePage.tsx`, `web/src/lib/verify/report/compare.ts`). "Compare with another record" on every report opens it with that report on one side.
2. **The same rows for both**: verdict, luck check, tries counted, trades, dates, profit per trade, win rate, profit factor, total return, largest fall, longest time under water, wins wiped out by the worst loss, Sharpe a year, checks failed, what could not be checked and the method. Each number explains itself.
3. **No ranking.** One sentence states both verdicts and says Parity does not rank them. Red marks only the side with the deeper fall, the longer time under water, the weaker luck check or more failed checks; returns are never marked.
4. **Growth over the same days**: both growth lines from the first day both records cover, when they share enough days; otherwise the page says why.
5. **A batch row's report**: the account's own trades go through Verify's checks in the firm's browser and the report opens in a new tab with everything in its address, so the traders' data still never reaches Parity. The report shows the screen's own verdict beside Verify's, which asks more of a short record.

## Consequences

- Choosing between two bots is one page, with the same numbers for both and nothing ranked.
- Files: `web/src/verify/ComparePage.tsx`, `web/src/verify/compare.css`, `web/src/verify/compareMain.tsx`, `web/verify/compare/index.html`, `web/src/lib/verify/report/compare.ts`, `web/src/business/accountReport.ts`, tests in `web/tests/verify/report.test.tsx` and `web/e2e/verify-report.spec.ts`.
