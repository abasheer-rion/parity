# Glossary

## Summary

Short definitions of terms used across the repo. Metric definitions with formulas are in [REF-0002](0002-kpis.md).

## Terms

| Term | Meaning |
| --- | --- |
| Backtest | Running a strategy over past data as if it had been traded. |
| Basis point (bp) | One hundredth of a percent. |
| Carry | The interest you earn on the currency you hold minus the interest you pay on the one you borrow. |
| Commodity currency | A currency whose value tends to follow the price of the country's main exports, such as CAD and NOK with oil. |
| Deflated Sharpe ratio | A Sharpe ratio adjusted for how many strategies were tried. See [REF-0002](0002-kpis.md#robustness). |
| Drawdown | How far the equity curve sits below its previous peak. |
| G10 currencies | USD, EUR, JPY, GBP, CHF, CAD, AUD, NZD, NOK and SEK. |
| Information coefficient | Rank correlation between a forecast and what happened next. |
| Lookahead bias | Using information in a backtest that was not available at the time. |
| Out of sample | Data not used to choose a strategy's rules or parameters. |
| Overfitting | Tuning a strategy to past noise so it looks good in the backtest and fails afterwards. |
| Purchasing power parity (PPP) | The idea that exchange rates drift toward the level that equalises prices across countries. |
| Sharpe ratio | Return per unit of volatility. |
| Spot rate | The exchange rate for immediate delivery. |
| Terms of trade | The price of a country's exports relative to its imports. |
| Turnover | How much of the portfolio is traded, as a share of its size. |
| Uncovered interest parity (UIP) | The theory that a high-rate currency should weaken by the rate gap. It mostly fails in data, which is why carry has paid. |
| Volatility targeting | Scaling positions up or down so the portfolio's risk stays near a set level. |
