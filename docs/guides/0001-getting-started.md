# Getting started

## Summary

From a fresh clone to running every strategy and seeing the dashboard, in about ten minutes. You need Python 3.11 or newer, Node 22 or newer, git and curl.

## Steps

1. **Clone and set up.**

   ```bash
   git clone https://github.com/abasheer-rion/parity.git
   cd parity
   make setup
   ```

   `make setup` creates `engine/.venv`, installs the engine and the dashboard's packages, and turns on the git hooks that check docs and commit messages.

2. **Download data.**

   ```bash
   make fetch
   ```

3. **Run the strategies.**

   ```bash
   make run
   ```

   This prints a table and writes `engine/output/latest.json`.

4. **Open the dashboard on your machine.**

   ```bash
   make web
   ```

   With no Supabase settings it reads `engine/output/latest.json` directly, so you see your own runs.

5. **Run the checks before pushing.**

   ```bash
   make check
   ```

   This runs the engine tests, lint, the dashboard type check and the docs check, the same as CI.
