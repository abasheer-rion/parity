## How it works

**Simple:** Markets are said to move in a repeating pattern of five steps up and three steps down. Figure out which step you are in and bet on the next one.

<details><summary>Analogy</summary>

Like believing every song follows the same verse-chorus pattern and guessing the next line from where you think you are.

</details>

<details><summary>Precise</summary>

Elliott held that prices move in five-wave impulses and three-wave corrections nested at every scale, with wave lengths related by Fibonacci ratios. Traders label waves by eye and, for example, buy the start of wave 3 after a wave 2 pullback. The rules for counting allow many valid labels for the same chart, so the method does not give a single testable signal.

</details>

### The rule

Commonly taught: after an apparent five-wave advance and a three-wave (A-B-C) correction that retraces 50 to 61.8 percent of wave 1, buy for wave 3, stop below the start of wave 1, target 1.618 times wave 1. There is no agreed algorithm for labeling waves.

### Data needed

- Daily or intraday prices

### Why it might work

Proponents (Prechter) tie waves to swings in crowd mood. No academic paper we read supports it.

### Why it might fail

There is no credible evidence. Because the same chart can be counted in several valid ways and counts are revised after the fact, the method is close to unfalsifiable as practiced. Any code version is a researcher's own choice of rules, not 'the' Elliott wave.
