Connect Gemini to Parity

Last checked against Google's docs: 26 October 2026

Add Parity to Gemini CLI and Gemini can verify a trade record, one of our tested strategies or a seller's claim, and read tested strategies, market data and Academy lessons from your terminal. Gemini reads your Parity data as you and cannot change anything unless you allow it.

Which Gemini? Gemini CLI, Google's Gemini in the terminal, connects to Parity today. We could not find a way in Google's docs to add your own server to the Gemini app on the web or phone. When Google adds one, this page will say how.

The address

1. Add Parity to Gemini CLI

Either run one command:

gemini mcp add --transport http parity

Or add this to ~/.gemini/settings.json (for every project) or .gemini/settings.json in one project. If the file already has mcpServers, add the parity entry inside it.

{
  "mcpServers": {
    "parity": { "httpUrl": "" }
  }
}

Use httpUrl, not url. In Gemini CLI, url means an older kind of server and will not connect.

2. Sign in

  1. Start Gemini CLI with gemini.
  2. Type /mcp auth parity. Your browser opens Parity's log-in page.
  3. Log in, check the Allow page names Gemini CLI and a localhost address, and choose Allow. The browser says you can close it.
  4. Type /mcp to see Parity listed with its tools. Then ask, for example, "Use Parity to show the market series for EUR and its last value."

5. Privacy

Gemini CLI keeps its sign-in for Parity on your computer, in ~/.gemini/.

6. Disconnect

  • From Parity: open Connect your AI, find Gemini CLI under "Your connected apps" and choose Disconnect. Its next call fails and it has to sign in again.
  • From Gemini CLI: run gemini mcp remove parity, or delete the parity entry from settings.json.
  • To stop changes but stay connected, untick "May make changes" for Gemini CLI on Connect your AI.

7. If it does not work

  • Parity shows as disconnected. Run /mcp auth parity again. Sign-ins expire.
  • It never asks you to sign in. Check the entry says httpUrl and the address ends in /mcp.
  • The browser does not open. Gemini CLI prints the sign-in link. Copy it into a browser on the same computer.
  • "This request has expired or is not valid". The sign-in link is single use. Run /mcp auth parity again.
  • "Too many calls". You reached 30 calls in a minute or 1000 in a day. Wait and ask again.
  • Still stuck? Email contact@paritytrading.app with the time it failed and what Gemini CLI printed.
