Connect Claude to Parity

Last checked against Anthropic's docs: 26 October 2026

Add Parity to Claude and Claude can verify a trade record, one of our tested strategies or a seller's claim, and read tested strategies, market data and Academy lessons, all from a chat. Claude reads your Parity data as you and cannot change anything unless you allow it.

The address

1. Claude on the web, desktop and phone

Add Parity once on claude.ai and it works in Claude Desktop and the Claude phone app too. Every plan can add custom connectors. The free plan allows one.

  1. On claude.ai, open Customize, then Connectors. On a Team or Enterprise plan, an owner adds it under Organization settings, then Connectors.
  2. Choose Add, then Add custom connector.
  3. Name it Parity and paste the address above as the server URL. Leave the advanced settings as they are. Choose Add.
  4. Choose Connect. Claude opens Parity's log-in page. Log in with your Parity account.
  5. Parity shows its Allow page. Check it names Claude and claude.ai, then choose Allow. You land back in Claude, connected.
  6. In a chat, open the tools menu and make sure Parity is on. Then ask, for example, "Using Parity, which tested strategies beat the S&P 500?"

2. Claude Code

Run this in a terminal. Add --scope user after add to have Parity in every project.

claude mcp add --transport http parity
  1. Start Claude Code and type /mcp.
  2. Choose parity, then sign in. Your browser opens Parity's log-in page and then the Allow page.
  3. Back in Claude Code, ask "Use Parity to get the results of the fx_carry strategy."

Claude Code can also run the local Parity server, which adds backtests. That needs the repository; see the developer guide.

6. Disconnect

  • From Parity: open Connect your AI, find Claude under "Your connected apps" and choose Disconnect. Claude's next call fails and it has to ask you to log in again.
  • From Claude: open Customize, then Connectors, choose Parity and remove it.
  • To stop changes but stay connected, untick "May make changes" for Claude on Connect your AI.

7. If it does not work

  • The log-in page does not open. Check the address ends in /mcp with no space or slash after it. Allow pop-ups for claude.ai.
  • "This request has expired or is not valid". The sign-in link is single use. Go back to Claude and choose Connect again.
  • Claude says it cannot place an order. Changes are off. Tick "May make changes" for Claude on Connect your AI. Orders are demo orders only.
  • "Too many calls". You reached 30 calls in a minute or 1000 in a day. Wait and ask again.
  • Claude does not use Parity. Check Parity is switched on in the chat's tools menu, and name it in your question: "Using Parity, ...".
  • Team or Enterprise. Only an owner can add a custom connector. Ask yours to add the address above.
  • Still stuck? Email contact@paritytrading.ai with the time it failed and the message Claude showed.
