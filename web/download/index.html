Parity for Mac and Windows

The desktop app opens the whole Parity site in its own windows: Verify, Strategies, Research, Terminal, Trade, Academy and Workbench. It keeps you signed in and updates itself.

Not sure which Mac you have? Open the Apple menu, then About This Mac. "Chip" means Apple silicon. "Processor" means Intel.

System requirements

  • Mac: macOS 12 Monterey or later.
  • Windows: Windows 10 or 11, 64-bit.
  • An internet connection for the live site. Without one, the app shows the copy of the site it was built with.

Signed and notarized

The Mac app is signed with an Apple Developer ID and notarized by Apple, so it opens without a warning. The Windows installer is signed. Both are signed by Argus Vision, Inc. While the Windows signature is new, Windows may still show "Windows protected your PC". Click More info, then Run anyway.

Updates

The app checks for a new version 15 seconds after it opens and every 6 hours after that. It downloads the update in the background and asks to restart. You can turn this off in Settings. Pages inside the app are always the live site.

Checksums

To check a download, compare its SHA-256 checksum with the one below. On a Mac, run shasum -a 256 followed by the file. On Windows, run certutil -hashfile followed by the file and SHA256.
