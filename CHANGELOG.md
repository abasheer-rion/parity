# Changelog

Changes to code and infrastructure that someone else would notice. Reasoning and results live in [docs/](docs/README.md); this file links to them rather than repeating them.

## Unreleased

- Auth emails: the reset, sign-in code and resend buttons count down when an email was sent in the last 30 seconds instead of saying "Too many emails", and a mail failure now says the email could not be sent. Limits raised to 200 emails and 60 code sign-ins an hour, 30 seconds between emails to one address. The six auth emails are redesigned ([auth/README.md](auth/README.md)): Invicta blue, light and dark mode, the logo from `/email/` as a PNG, shorter copy, a large code, and a footer with the company address. Sender name is "Parity Trading".

Download links in the site header and footer, the front page, Account settings and the app's Help menu.
